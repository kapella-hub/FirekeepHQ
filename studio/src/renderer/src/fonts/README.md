# Studio fonts

The same three families firekeep.ai self-hosts, bundled so Studio never fetches a font
(its CSP is `font-src 'self'`). All are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org).

| File | Family | Used for |
|---|---|---|
| `space-grotesk-latin.woff2` | Space Grotesk (variable, 300-700) | The wordmark and headings |
| `dmsans-latin*.woff2` | DM Sans (variable, 400-700) | Interface and reading text |
| `jetbrainsmono-latin*.woff2` | JetBrains Mono (variable, 400-600) | Code and commands |
