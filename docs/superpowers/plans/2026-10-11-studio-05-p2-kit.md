# Studio 0.5 prerequisite 2/3 — Client kit 1.8.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give Firekeep Studio what it needs from the kit: a narrow gateway toolset, a secret-free identity command, a way to learn which Keep sessions its agents started, and session attribution for hook-pushed recall.

**Architecture:** Five small, independent changes to `client/firekeep_client`:
- a `studio` entry in `TOOLSET_PRESETS`;
- a `firekeep whoami [--json]` subcommand;
- a session report file: when `FIREKEEP_SESSION_REPORT_FILE` is set, the bridge shim's session tap appends every Keep session id it captures;
- Codex forwarding for that variable (`env_vars`);
- `promptrecall` stamping its recall with the agent's current Keep session.

None of them changes behaviour when the new variable is unset.

**Tech Stack:** Python 3.11 stdlib (cli, hooks, resolver and state must stay stdlib-only — `tests/test_import_boundary.py` rule 2), pytest. Only `shim.py` may import `mcp`/`httpx`.

**Spec:** `docs/superpowers/specs/2026-10-11-studio-keep-window-design.md` §7.1 (preset, `whoami`) and §7.2 (report file, Codex, prompt-recall attribution).

**Release order:** plan 1 (server `v1.6.2`) → **this plan (client `1.8.0`)** → plan 3 (Studio 0.5.0). This plan does not depend on plan 1.

## Global Constraints

- The `studio` preset is exactly: `memory_recall`, `memory_feedback`, `skill_list`, `skill_recall`, `relay_who_is_online`, `relay_read`, `ctx_list_sessions`, `replay_timeline`, `corpus_sources`. Studio never starts, updates or completes a Keep session (§7.1, §7.2).
- An unknown `FIREKEEP_TOOLSET` still fails closed (unchanged message, which now lists `chat, studio`).
- `firekeep whoami` never prints the API key or any `[server]` value other than "configured or not".
- The environment variable is spelled `FIREKEEP_SESSION_REPORT_FILE`. With it unset, every code path behaves exactly as in 1.7.2.
- A session id is written to, or read from, the report file only if it matches `^[A-Za-z0-9][A-Za-z0-9._:-]{0,127}$`. Ids end up in an HTTP header, so a newline must never pass.
- Report-file I/O never raises into a tool call or a hook.
- New version: **1.8.0** (new subcommand and new environment contract, so a minor bump).

## Review Focus

1. **The report path's directory is missing or read-only** — the tool call must still succeed and the session must still be stashed. Pinned by `test_unwritable_report_path_never_breaks_capture` (Task 3).
2. **A hostile or garbled session id** (newline, 300 chars) — never appended, never returned as a header value. Pinned by `test_report_rejects_ids_that_could_split_a_header` (Task 3).
3. **An installed Codex older than `env_vars` support** — must not be broken by the rendered key. Covered by a manual verification step in Task 4 (no automated test can install Codex versions).
4. **`FIREKEEP_SESSION_REPORT_FILE` unset** — tap writes nothing, header choice unchanged. Pinned by `test_no_report_env_means_no_report_file` and `test_tapless_auth_without_report_env_is_unchanged` (Task 3).
5. **`whoami` on a machine with no config** — prints JSON with `agent_id: null` and exits 1; no traceback. Pinned by `test_whoami_without_config_is_null_not_a_crash` (Task 2).

```python
def cmd_whoami(args) -> int:
    """Identity facts a local client (Firekeep Studio) needs — never the API key.

    Studio must not read ~/.firekeep/config itself because the file holds the
    key, so this is the one place it learns the agent id (spec 2026-10-11 §7.1).
    """
    cfg = None
    try:
        cfg = resolver.load_config(_config_path())
    except resolver.ConfigMigrationConflict as exc:
        print(f"firekeep: {exc}", file=sys.stderr)
        return 3
    except resolver.ConfigError:
        cfg = None
    agent: str | None = None
    if cfg is not None:
        try:
            agent = resolver.agent_id(cfg)
        except resolver.ConfigError:
            agent = None
    facts = {
        "agent_id": agent,
        "kit_version": __version__,
        "personal_mode": bool(resolver.is_personal()),
        "server_configured": bool(cfg is not None and wizard._already_connected(cfg)),
    }
    if getattr(args, "json", False):
        print(json.dumps(facts))
    else:
        for key, value in facts.items():
            print(f"{key}: {value}")
    return 0 if agent else 1
```

```python
# Firekeep Studio 0.5 (spec 2026-10-11 §7.2): Studio launches each agent with
# this variable naming a per-Studio-session file. The bridge tap appends every
# Keep session id it captures, so Studio can build per-turn receipts from the
# sessions the AGENT started — Studio never starts one itself.
SESSION_REPORT_ENV = "FIREKEEP_SESSION_REPORT_FILE"
# Ids travel in an HTTP header (X-Session-Id): no whitespace, no newline, ever.
_SESSION_ID_RE = re.compile(r"[A-Za-z0-9][A-Za-z0-9._:-]{0,127}")


def _report_path() -> str | None:
    raw = os.environ.get(SESSION_REPORT_ENV, "").strip()
    return raw or None


def append_session_report(session_id: str) -> None:
    """Append a captured Keep session id to $FIREKEEP_SESSION_REPORT_FILE.
    No-op when the variable is unset or the id is not header-safe. Never raises."""
    try:
        path = _report_path()
        if not path or not isinstance(session_id, str) or not _SESSION_ID_RE.fullmatch(session_id):
            return
        with open(path, "a", encoding="utf-8") as fh:
            fh.write(session_id + "\n")
    except Exception:
        pass


def reported_session_id() -> str | None:
    """The last header-safe id in $FIREKEEP_SESSION_REPORT_FILE, else None."""
    try:
        path = _report_path()
        if not path:
            return None
        with open(path, encoding="utf-8") as fh:
            ids = [line.strip() for line in fh if _SESSION_ID_RE.fullmatch(line.strip())]
        return ids[-1] if ids else None
    except Exception:
        return None


def current_session_id(agent_id: str) -> str | None:
    """The Keep session this agent is working in: the fresh stash, else the
    Studio report file (which survives the stash clear a resumed runtime's
    session_start performs). Never raises."""
    try:
        stash = read_session_stash(agent_id) or {}
        return stash.get("session_id") or reported_session_id()
    except Exception:
        return None
```
